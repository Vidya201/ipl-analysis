# IPL Strategic Intelligence Analysis

Data-driven analysis of 1095 IPL matches across 17 seasons.

## Key Findings
- Toss winner wins only 50.59% of matches — toss has minimal impact
- Teams fielding first win 53.5% vs 45.3% batting first
- Mumbai Indians are best chasers with 90 wins while chasing
- Powerplay (103,217 runs) scores more than death overs (93,884 runs)
- V Kohli is all-time top scorer with 8014 runs

## Tech Stack
Python · Pandas · Matplotlib · Streamlit

## Dataset
IPL Complete Dataset from Kaggle — 1095 matches, 260,920 deliveries
